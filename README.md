# Tripva – Manual Testing Project

## Project Overview

This project contains manual testing documentation for the **Tripva** web application.

The testing was performed based on the application's currently available functionality, including accessible, preview, locked, and upcoming features.

## Application

**Application:** Tripva
**Website:** https://tripva.in/

## Testing Scope

The project covers:

* Functional testing
* UI testing
* Validation testing
* Negative testing
* Navigation testing
* Input field testing
* Bus search testing
* Notification/early-access testing
* Popular routes testing
* Roadmap/upcoming features testing
* Footer and link testing
* Basic compatibility and responsiveness testing

## Testing Documentation

The repository contains:

1. **Project Information** – Overview, scope, objectives, and application details.
2. **Application Exploration** – Features explored and their current availability/status.
3. **Test Scenarios** – High-level testing scenarios derived from the explored application.
4. **Test Cases** – Detailed manual test cases covering different functional and non-functional conditions.
5. **Test Execution** – Execution results for features that are currently available for testing.
6. **Defect Report** – Defects identified during actual testing, where applicable.

## Test Case Coverage

**Total Test Cases: 250**

The test cases cover positive, negative, boundary, validation, UI, navigation, and usability conditions.

> Note: Tripva is currently in a pre-launch/development stage. Some features are available only as previews or are locked/upcoming. Therefore, test execution is limited to functionality that is currently accessible.

## Testing Approach

The following approach was followed:

1. Explore the application.
2. Identify available and upcoming features.
3. Define test scenarios.
4. Create detailed test cases.
5. Execute applicable test cases.
6. Record actual results and status where functionality is available.
7. Document reproducible defects, if any.
